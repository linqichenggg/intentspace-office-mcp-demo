API 接続を設定する

ページに入力したKeyを優先します。一時Keyは再読み込み・離脱で消去します。本機のデフォルト設定がある場合は、サーバー側で使用します。

Key は HTTPS（ローカルでは本機内）でこのデモのサーバーに渡し、OpenAI への認証だけに使います。ページに入力した一時Keyはブラウザーの保存領域・Cookie・サーバーの保存領域・アプリログには記録しません。本機のデフォルトKeyは .env.local に保存し、サーバー側だけで使用します。ブラウザー自身のパスワード保存機能は使わないでください。OpenAI 側のデータ保持ポリシーは別途適用されます。
