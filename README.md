# 办公室数据 MCP Demo

真实 MCP Server + 本地查询页面，包含五个只读工具。页面通过官方 MCP Client 的 stdio 连接调用独立服务进程。界面采用手动选工具，不包含模型推理、主动监测、预约写入或实时空闲判断。

公开仓库只包含源码与 `demo-data/` 中人工编写的虚构数据（3 个空间、6 条预约）。没有企业 CSV、办公室平面图、人员数据或访问凭据。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm install
npm test
npm start
```

打开 http://127.0.0.1:4180 。依次演示预约统计、空间目录、预约明细及“来源记录”。

## 连接其他 MCP 客户端

配置 stdio 服务，command 为 Node 可执行文件绝对路径，args 为本目录 `server.js` 的绝对路径。也可用 `npm run mcp` 启动；stdio 服务没有网页。

## 数据更新

如果本机存在项目相邻目录 `../07_企业数据/2026-09-07_Bitkey/Data`，默认只读该目录；其他环境自动使用 `demo-data/`。设置 `OFFICE_DATA_DIR` 为另一个目录可接入同结构的三个 CSV；重启后重新读取。显式配置的路径无效时会报错，不会静默切换数据。这个版本没有自动同步或热更新。企业实时 API、数据库适配属于后续工作。

验证公开虚构数据：`OFFICE_DATA_DIR=./demo-data npm test`。启动虚构数据界面：`OFFICE_DATA_DIR=./demo-data npm start`。

所有回答包含覆盖范围、加载时间、源文件 SHA-256 和限制。源更新时间未知，不用加载时间冒充现场更新时间。日期按源数据预约开始日期筛选；超出样例日期范围拒绝查询。提供方时区语义仍需确认。容量 0/空值为未知；统计按记录计数，不代表小时利用率或可自动释放数量。

服务只监听本机。当前演示只提供空间和预约字段，不返回人员身份。本版尚未具备远程认证与多租户授权，不能直接公开部署。
