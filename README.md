# IntentSpace オフィスデータ MCP デモ

オフィスデータを検索・集計する、読み取り専用の MCP Server とローカル Web 画面です。Web 画面から MCP Client を通じて独立したサーバープロセスを呼び出し、結果と参照元を確認できます。

現在は利用者が画面でツールと条件を選択します。AI モデルによる対話・提案、変化の自動検知、予約の作成・変更、リアルタイムの空き状況判定は未実装です。

## 公開範囲

公開リポジトリにはソースコードと架空のデモデータのみを含みます。`demo-data/` の 3 スペース・6 件の予約は、動作確認用に作成したものです。企業提供の CSV、フロアマップ、個人情報、認証情報は含みません。

## 起動方法

Node.js 22 以降を使用してください。

```sh
npm ci
npm test
npm start
```

ブラウザーで http://127.0.0.1:4180 を開きます。

1. 「予約と利用」で、指定期間の記録をスペース別に集計します。
2. 「スペース一覧」で、名前からスペースを検索します。
3. 「予約明細」で、状態や日時を確認し、「参照元を確認」を押します。
4. 「ツール呼び出しと返却データ」を開くと、入力パラメーターと実際の MCP 応答を確認できます。

## MCP ツール

| ツール | 内容 |
| --- | --- |
| `get_data_status` | 対象期間、読み込み時刻、件数、元ファイルのハッシュ値と制約 |
| `search_spaces` | 名称・種別・登録定員で検索 |
| `query_reservations` | 開始日・スペース・状態による予約検索とページング |
| `summarize_reservations` | スペース別の予約・利用・未利用・状態別件数 |
| `get_evidence` | 予約 ID に対応する記録と参照元の論理レコード番号 |

画面のスペース検索では、読み込んだ予約データに登場するスペースを対象にします。予約可能なスペースの現在の一覧を保証するものではありません。

## 他の MCP クライアントから接続

stdio 接続を使用します。クライアントの設定で、`command` に Node.js の実行ファイル、`args` にこのリポジトリの `server.js` の絶対パスを指定します。

```json
{
  "mcpServers": {
    "office-data": {
      "command": "node",
      "args": ["/absolute/path/to/intentspace-office-mcp-demo/server.js"]
    }
  }
}
```

設定形式はクライアントによって異なります。`npm run mcp` でも MCP Server を起動できます。stdio サーバー単体には Web 画面はありません。

## データの差し替え

次の 3 ファイルを、サンプルと同じ項目構成で用意します。

- `spaces.csv`：スペースの名称、種別、定員など
- `reservations.csv`：予約日時、利用・キャンセル状態など
- `reservations_classified_mapping.csv`：予約 ID と会議分類

`OFFICE_DATA_DIR` にディレクトリを指定し、再起動すると読み込まれます。

```sh
OFFICE_DATA_DIR=/absolute/path/to/private-data npm start
```

明示的な指定がなければ、本プロジェクトの既存作業環境にある相対パス `../07_企业数据/2026-09-07_Bitkey/Data` を確認します。このディレクトリが存在しない環境では、公開リポジトリの `demo-data/` を使用します。明示的に指定したパスが無効な場合はエラーになります。

架空データでの検証と起動：

```sh
OFFICE_DATA_DIR=./demo-data npm test
OFFICE_DATA_DIR=./demo-data npm start
```

現在の読み込みは起動時のみです。自動同期、企業 API、データベース接続は今後の対応範囲です。データモデルは提供されたデータの種類をもとに設計し、実運用時には更新データへの接続を想定しています。

## 集計条件と制約

- 応答には対象期間、読み込み時刻、元ファイルの SHA-256 と注意事項を付けます。
- 元データの更新時刻は不明です。読み込み時刻を現場の状態更新時刻として扱いません。
- 日付検索は元データの予約開始日を基準とします。検索期間は両端を含みます。対象期間外の検索は拒否します。
- 企業サンプルの JST 項目に UTC 表記があるため、時刻の意味は確認が必要です。自動的な時差変換は行いません。
- 「事前キャンセルを除く未利用」は `is_reserved=true` かつ `is_used!=true` の件数です。バーはその件数を `is_reserved=true` の件数で割った割合です。
- 時間ベースの稼働率、改善効果、予約の自動解放可否は、この集計だけでは判断できません。
- 定員は元データの登録値です。空欄と 0 は不明として扱います。

## 構成

```text
Web 画面（index.html / app.js / styles.css）
  → MCP Client（web.js）
  → MCP Server（server.js）
  → 読み込み・検索・集計（data.js）
  → CSV
```

`test.js` は実際の MCP 接続を使用し、ツール一覧、集計と明細の一致、参照元、日付の入力エラーなどを確認します。

サービスはローカルホストのみで待ち受けます。個人の識別情報は返しません。遠隔アクセス用の認証やマルチテナント権限制御は未実装です。
